## Notes

- Nothing is **Blocked**. The Phase 16 live rehearsal (16a–16e) closed the items that were pending after Phase 15.
- Paths that are only proven in the sandbox or app tests, never live: an unknown transaction outcome (landed or lost), two release workers at once, a failed token transfer with bounded retries, a worker crash between claim and signing. They need fault injection that testnet does not allow safely. They are labelled the same way in README and BUILD-STATE.
